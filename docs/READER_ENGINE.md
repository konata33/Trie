# 阅读引擎

阅读引擎把文章从订阅源或原网页取回，提取正文、清理、内嵌图片、规范化后存进资料库，再用应用自己的排版显示。它保留文字、代码、图片和文章结构，不带源站的样式、布局和脚本；拿不到全文、内容受限或图片失败时如实说明。阅读质量不能为任何别的功能退步。

```text
订阅源正文 / 原网页 → 取回 → 提取与清理 → 内嵌图片 → 排版与规范化 → 保存 → 按块显示
```

「已取得正文」指取得了来源给出的可读内容，不证明它是作者网页的全部内容。

## 来源选择

- 订阅源带正文时先读它：受限、有 1,500 字以上，或条目指向页面中的一段时直接采用；更短的作为候选，再读原网页。
- 原网页字数超过订阅源 1.5 倍才替换它；原网页读不出，或受限且更短时，用订阅源的版本。订阅源正文只有图时，原网页要有 600 字以上才采用。
- 订阅源只给描述，或给的是 600 字以内、以「阅读全文」一类链接结尾的引子时，记为摘要。
- 都读不出时，从网页或主页声明的订阅源里最多再试两个。

## 提取、清理与图片

- 页面只有一个 article（或只有一个 main）且文字占全页十分之一以上时只在它里面提取；否则页面要标明是文章或由订阅源链接过来，才整页提取。提取用 Readability 算法，最多 20,000 个元素，字数阈值 120。
- 提取前去掉脚本、样式、表单、导航、页眉页脚、侧栏、隐藏元素、评论、相关文章、分享区、付费墙和登录弹窗，以及类名标明只在窄屏显示的元素（mobile-only、only mobile、md:hidden、d-md-none、visible-xs 这类，页面另有给宽屏的一份），这样标明的小标题留下；提取后去掉开头重复的标题、日期行和标签，只链到本页标题的目录列表，以及订阅源正文的转载声明和「阅读全文」链接。
- 图放在正文旁边另一个容器里的页面（摄影、作品集、杂志），图按页面上的先后放回正文：从提取到的正文往外找，取多出图最多、文字比正文多不到四分之一加 100 字的一层；找到后再往外，文字多出 40 字以上就停。页面只有一个 article 或 main 时不越过它；导航、页眉页脚、侧栏里的图，SVG，名字里有 logo、avatar、icon、button、anchor 的图，标明宽不到 300 或高不到 200 的图不算。排在第一段文字之前的图不超过 3 张时作为题图留在文字前；多于 3 张时是和文字并排的图栏或随文字滚动切换的幻灯片，按原来的先后放到文字后面。
- 排版时再整理一遍，网页正文和订阅源正文一样，已存的正文重排时也照做：开头最多两行的翻译版本链接（Translations:）、「Read on 网站」和只有日期的一行去掉；结尾最多三行的广告标记（ADS）、「The post … appeared first on …」、「Read on 网站」、订阅邀请（Sign up / Subscribe … newsletter）和转载、著作权声明去掉，往前找时越过图片和分隔线，300 字以上的段落不算。第一段以 Summary:、TL;DR:、Abstract:、摘要：、导语：开头、标签后还有 20 字以上时，去掉标签，记为导语。一串紧挨着的图（中间没有别的）图注相同时，只留最后一张的。
- 表格里各格都没有字也没有图的行去掉，跨进这一行的格子少跨一行。没有表头（th、thead、caption），又只有一行或一栏、只有图没有字，或里面套着表格的，是拿表格排版：拆成普通段落，各格按先后排开，格里的块照原样，零散的字和图连成一段；代码旁边只有行号 1、2、3… 的一格去掉。
- 小标题和表格单元格两端看不见的东西去掉：各种空白（包括图标留下的不换行空格）、换行和空的行内元素，带锚点的空元素留下。紧接在同级同字（不分大小写）的小标题后面、中间只隔着没有字也没有图的块（空段落、分隔线）的小标题去掉。
- 页面分段输出时（React 先放占位框、后补内容），后补的内容换下占位框，「Loading...」这类占位字不留。
- 代码框上方单独一行的语言名（TSX、CSS）读成代码的语言，这一行和框里的「复制」按钮去掉；写的是 Text 或 Plain 时代码按纯文本显示。
- 订阅源正文里夹在两个段落之间、单独一行、100 字以内、不以句末标点结尾的文字读成小标题，比正文自己最高一级的小标题高一级，最高二级。
- 清理按白名单保留段落、标题、列表、引用、代码、表格、图与图注、链接、图片、分隔线和常见行内格式；属性只留锚点、链接、图片说明与尺寸、跨行跨列、列表起始序号和代码语言。
- 不足 120 字的页面视为没有正文，带图注或标题的图片文章除外；超过 2,000,000 字节或 20,000 个元素的页面不解析。
- 图片每篇最多 64 张、同时 6 张，单张 8 MB、全篇 15 MB；阅读时等 45 秒，探索预览等 6 秒。srcset 取宽度不小于 1600 的最小一张；1×1 的统计像素去掉。
- 类型按文件头判断；SVG 经过清理；AVIF 用系统自带的 sips 转成 PNG 或 JPEG；页面内嵌的图片数据不超过 512 KB 且内容与类型相符才保留；指明了 Excalidraw 场景的空白板画成 SVG。

## 数据

| 部分 | 内容 |
| --- | --- |
| 显示用正文 | 清理、排版后的 HTML，图片已内嵌 |
| 来源正文快照 | 提取清理后、内嵌图片和排版之前的 HTML |
| 规范化文档 | 见下文 |
| 状态 | 全文、摘要、受限、不可用之一，附一句说明 |
| 来源 | 原网页还是订阅源、实际地址、获取时间、订阅源正文的版本 |
| 图片 | 图片缓存版本（4）和缺图张数 |

规范化文档版本为 1，由排版版本 6 生成：

- **结构树**：hast 格式，只含阅读器允许的标签和属性；图片只能是内嵌数据，链接只能是 http(s) 或页内锚点。
- **阅读单元**：标题、段落、列表项、图注、代码、图片、表格单元格，各记类型、自己直接拥有的文字和原有锚点。标识由类型、文字、结构的指纹加出现次数生成，规则不变时可重复生成，内容相同的段落也能区分。
- **内容版本**：对标签、影响含义的属性和文字求 SHA-256，不含阅读器加的外层、代码栏、提示块标题和图片缓存状态；有快照时按快照计算。
- **单元版本**：对有序的单元类型、标识和文字求 SHA-256。
- **来源标记**：「来源」按新取得的正文生成；「旧缓存」从没有快照的旧缓存迁移而来，内容版本按显示用正文计算，不冒充原文快照。
- **代码高亮提示**：只供显示，不进入内容版本。

上限：50,000 个节点、嵌套 128 层、10,000 个单元、单元文字 2 MB、单张图片 12 MB、图片合计 24 MB。文档生成后和保存前都要通过结构校验。

阅读位置记内容版本、所在单元和偏移，内容版本变了就不恢复。摘录记文字、起始单元和内容版本，打开时按文字（忽略空白）找回位置，找不到就不标出。

## 缓存与更新

- 订阅源正文版本没变、排版版本是当前的、文档有效时，直接用已存的正文；排版版本旧或文档无效时，用已存的 HTML 和快照离线重排并存回。
- 点「重试」、图片缓存版本低于 3 且有缺图、已存的订阅源正文是引子、已存的订阅源正文里还有没读成小标题的单独一行、已存的网页正文里留着「Loading...」占位字时重新读取。
- 图片缓存版本低于 4 的网页正文（作品页除外）和还不是作品页的画廊条目，在阅读页打开时照常先显示已存的版本，同时在后台重读一次，光标停在列表行上的预读不重读：读到全文、缺图不比原来多时存下新的，并通知阅读页换上：阅读页还停在文章开头附近（往下不到 240px）时当场换上，位置不动；已经往下读了就等离开这篇时再换，读着的字不在眼前变动；读不到、读到的更差，或重读期间在阅读选项里换了来源时，保留已存的，不提示，下次打开再试。画廊以外、只有订阅源正文的文章不在后台重读。
- 新结果不如已存的（已存的是全文而新的不是，图片缓存版本 3 及以上、图片齐全而新的缺图，新的排版失败）时保留已存的；读取期间订阅源正文变了，新结果不保存。
- 同一篇文章同时只读一次；连接被重置或 DNS 暂时失败时，隔 0.4 秒、1.2 秒各重试一次。
- 图片的请求没得到回应（连不上或连接断开、域名暂时查不到、15 秒收不到数据、超过 60 秒）时，在等图的时间内排到最后再要一次；域名不存在、被拒绝、不是图片或超过大小的不再要。留着复用的连接 5 秒收不到任何数据就探测一次，再过 5 秒没有回应就关掉，下一个请求换新连接。

## 内容规则

| 内容 | 显示 | 不支持或失败时 |
| --- | --- | --- |
| 导语 | 标着 Summary: 等的第一段去掉标签，按导语显示，见 DESIGN.md Reading | 没有标签的第一段按普通段落 |
| 段落与行内格式 | 统一字号、行距、段距；保留链接、粗体、斜体、删除线、上下标、行内代码和换行；中日文与拉丁字母相邻处加 1/8 字宽 | 不认识的行内标签只留文字 |
| 标题与目录 | 保留有效的原锚点，重复的加序号，缺的按文字生成；读过的小标题停在阅读页顶边，见 PAGES.md 阅读器 | 没有标题时不显示；独立成段的 `[[toc]]`、`[toc]` 移除，代码和引用里的保持原样 |
| 提示块 | 引用开头的 `[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]`、`[!CAUTION]` 转成带标题的提示块 | 其他写法保持普通引用 |
| 列表 | 保留顺序、起始序号和嵌套 | — |
| 代码块 | 保留空格和换行；语言在 Shiki 内置语言表里才保留，否则标「纯文本」；按语言着色；Shiki 标注（`[!code hl]`、`highlight`、`++`、`--`、`word:词[:行数]`）读成标出的行和词，标注从代码里去掉，单独占一行的标注连同这一行去掉、标给下一行；复制按钮复制去掉标注后的代码；长行横向滚动 | 第 128 个之后或累计超过 2 MB 的代码块没有代码栏和复制按钮 |
| 表格 | 保留表头、跨行跨列，格子按浏览器的排法占位：排在同一行前面的格子和从上面跨下来的格子之后；开头整行都是表头的几行算表头；除表头外整列都是数字（可带正负号、货币符号、千分位和单位）的右对齐；每栏按最宽那格排成一行的宽度，最宽 360，但至少放得下这一栏最长的词（不超过正文栏宽）；跨栏的格子放不下时，把它跨的几栏按原宽的比例加宽；放不下时横向滚动；样式见 DESIGN.md Reading | 没有行的表格不显示；拿表格排版的拆成段落 |
| 图片与图注 | 按原尺寸或比例显示，不超过栏宽，太高的竖图缩到阅读区高度的 80% 居中；一组紧挨的图间距收紧；只交代出处的图注按署名显示；GIF 播放，SVG 里的文字叠画在图上；可放大查看；大小、成组、署名和圆角见 DESIGN.md Reading | 原位显示缺图图形和「重试」，已知比例时保持比例；重试重新读取整篇 |
| 页内链接与脚注 | 在正文里跳转到锚点 | 目标不存在时不动 |
| 外部链接 | 只保留不含账号密码的 http(s) 地址，用系统浏览器打开；正文里照原样留下的 magic link 写法读成链接：`{@用户}`、`{@用户\|名字}` 链到 GitHub 上这个人，显示名字（没有名字时显示用户名），`{名字\|网址}` 链到网址；代码里的不读 | 其他地址只留文字 |
| 公式、图表、交互组件 | 已渲染成图片的图表按图片显示 | MathML、内联 SVG、内嵌网页和嵌入对象连同内容移除，视频和音频只留文字；含小标题的互动图换成「互动示例，在原网页查看」的链接 |
| 设计画廊条目 | One Page Love、Awwwards 的条目读成作品页：录屏、首屏、站点、资料和截图；从探索打开和订阅后打开一样 | 其他画廊不足 600 字、自己的图不到 2 张的条目，用订阅源给的图、名字和站点拼成作品页；订阅源没有图时用网页自己声明的封面图（og:image） |

阅读时间按每分钟 400 个汉字或 230 个词估算，不计代码。

## 安全边界

- **不执行源站脚本**：脚本在提取前移除；服务端分段输出的片段只按固定格式的占位调用搬到位，不求值；JSON-LD 只当数据读。
- **只访问公网**：联网都经过取回模块。地址只能是 http(s)，不含账号密码和端口，主机不是 localhost、.local 或内网、保留地址；解析出的每个地址都要是公网地址（假 IP 段 198.18.0.0/15 只在解析结果里放行），连接直连检查过的地址，不走环境代理。
- **跳转与上限**：最多跳转 5 次，不从 HTTPS 降到 HTTP，网页和订阅源只在发布者域名内跳转。每次读取最多 160 个请求；DNS 6 秒，停滞 15 秒，单个请求最长 60 秒；网页和订阅源 2,000,000 字节，图片 8 MB，作品页录屏 16 MB。
- **图片只来自本机**：文档里的图片只能是内嵌数据，远程地址按缺图处理。SVG 拒绝 DOCTYPE、实体和处理指令，最大 256 KB、5,000 个元素、64 层，只留图形、渐变、裁剪、遮罩和文字，引用只能指向文件内。
- **解析隔离**：提取、清理、排版、SVG 和白板绘制在一个队列里逐个运行，每个最多 10 秒，超时或出错只让这次解析失败。
- **保存前校验**：显示用 HTML 最大 24 MB，整条记录最大 64 MB，规范化文档必须通过结构校验。

## 阅读状态与失败表达

| 状态 | 什么时候 | 怎么表达 |
| --- | --- | --- |
| 读取中 | 还没有正文 | 正文位置显示读取中的图形 |
| 全文 | 取得来源给出的可读内容 | 不加提示 |
| 摘要 | 订阅源只给摘要或引子 | 正文上方提示，附「重试」「阅读原文」 |
| 受限 | 标为付费、有付费墙或登录弹窗、原站返回 401 或 402 | 能确定付费区边界时只留公开部分，否则只显示发布者的公开简介；正文上方提示 |
| 不可用 | 提取不到正文、原站返回 403、地址无效 | 整页状态「正文暂时读不出来」，附原因、「重试」和「在浏览器打开」 |
| 缺图 | 图片没取到或没通过检查 | 只在图片原位表达，不改变正文状态 |
| 更新失败 | 重新读取或重新排版失败 | 继续显示本机保存的版本，没有时显示未经排版的正文；正文上方提示，附「重试」 |

## 尚未支持

- 逐段双语翻译。
- AI 快览。
- 公式和 Mermaid 源码的渲染。
- 明确标注为 Markdown 的输入。

加入翻译和快览时：结果另存，不覆盖原文，也不算进内容版本；结果绑定文章、内容版本、单元版本和单元标识，版本变了就重新生成；只接收纯文本或通过校验的行内结构，不接收可执行的 HTML；失败或只完成一部分时不遮住原文；基于摘要的结果说明它不是全文。
