# Trie 产品

## 是什么

一个 macOS 桌面应用：找值得借鉴的设计，读值得读的文章，把看中的交给 Claude Code 或 Codex，用进手上的项目。

Trie 的价值在挑选：设计网站、画廊和作者都由 Trie 挑过，打开就有好东西看，不用先订阅，也不用自己找来源。它不是 RSS 阅读器；订阅只用来跟着读几位作者。

## 给谁用

也做设计的开发者，在 Mac 上和 Claude Code、Codex 一起做产品。三种时候打开 Trie：

- **手上有要做的东西**：一个落地页、一组按钮、一段动效，还不知道什么风格好。按要做的东西找，一屏扫过很多，挑几个细看，留下来，交给 agent。
- **手上没有要做的东西**：看看今天有什么好的设计和文章，好的先留下，将来用得上。
- **回头用**：按要做的东西，翻出以前留下的。

文章是核心：读优秀的设计和工程文章，自己读，也把其中的做法交给 agent。

## 怎么组织

- 按要做的东西组织：落地页、按钮、动效这些是第一层；网站、画廊和作者是第二层。
- 点作品或标题，进作品页或文章；点作者的头像、名字或署名，进作者页。全应用都这样。
- 顶层页是首页、收藏、探索、摘录。往下最多两层：作者页，文章或作品页。
- 返回键写着回到哪里；返回时回到点开的那一项，滚动位置和焦点不变。点侧栏里的顶层页，回到那一页的顶上。
- 订阅、收藏、摘录都在原处完成，不换页。
- 启动时打开首页。

## 能做什么

- **首页：今天**。Trie 每天挑出的好设计和好文章，各种类型都有，不靠订阅：新装的应用打开就是满的。首屏是今天的一件设计；下面是读到一半的文章，可以接着读；再下面是好文章和订阅的作者的新文章。首页有尽头，不推荐订阅。
- **探索：找**。从要做的东西进去：设计分落地页、作品集、动效、字体、品牌五类，一类一面作品墙，一屏扫过很多，点开看作品页。归类按网站，不逐件判断：每一类取挑好的画廊，或画廊自己按这一类分好的栏目；什么都收的画廊不归类。往下是不分类的流，一直往下，没有尽头。来源是 Trie 挑的目录（约 57 个：中文独立博客、英文设计工程师、设计写作和通讯、灵感画廊、设计展示站），加上上游推荐的作者（Hacker News 摘要、UX Collective、Latent Space、Lobsters）。设计网站的首屏由应用在后台截取，保留 30 天。
- **作者页**：每位作者、每个网站一页，列出他的文章或作品，订没订阅都能看。订阅按钮在作者页的页头。
- **订阅**：跟着读某位作者：他出现在侧栏，他的新文章出现在首页。启动时重新读一遍订阅。没有已读、未读：不计数、不筛选、不标记已读；只记阅读进度，读到一半的文章可以接着读。
- **阅读器**：结构化的正文；设计画廊的条目按作品页读（录屏、截图、配色、字体、技术）。从哪里打开都一样，都能收藏、摘录。
- **收藏**：一下就收。设计跟着它在探索里的类别走，第一屏是按类排的灵感板；文章按作者放。取消收藏当场生效，可以从提示里撤销。搜索按标题或作者找。
- **摘录**：带出处。
- **交给 agent**：摘录卡把段落、出处、链接和想法复制成 Markdown，贴给 Claude Code、Codex 或笔记。
- **计划中，刻意做小**：翻译和 AI 精读。

每页具体长什么样见 [PAGES.md](PAGES.md)。

## 约束

- 联网只走应用的抓取层，只访问公网地址；网页、图片和录屏都取回存在本机，界面只显示本机的副本。
- 界面语言有中文和英文，跟随系统：系统语言是中文时显示中文，其他语言显示英文；读者可以自己改。内容有中文和英文。
- 平台：macOS 桌面，原生界面。深色优先。
- 天体主题是气质，不是词汇：深、静、精确，落在细节和精致上。界面、文案和命名里不新增天体符号或术语；月相只表示阅读进度，轨道只表示收藏。
- 视觉规则在 [DESIGN.md](DESIGN.md)，各页规格在 [PAGES.md](PAGES.md)；改任何界面前先读。
- 阅读质量是核心，不能为任何别的功能退步。
