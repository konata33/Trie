# Trie 产品

## 是什么

一个 macOS 桌面阅读器，读使用者自己挑的独立作者和设计网站。阅读第一；读到的东西变成可以借鉴的材料：一篇文章的想法，一个网站的版式、配色、字体和动效，交给 Claude Code 或 Codex，用进手上的项目。

它不是又一个 RSS 阅读器。「把所有新东西给我看」已经有通用阅读器（Folo 之类）在做；Trie 只管一小组挑过的来源，读得仔细。

## 给谁用

也做设计的开发者：读中英文的设计工程博客、设计写作和通讯，看设计画廊（One Page Love、Awwwards 之类）；在 Mac 上，多在晚上和两件事之间。要做的事：

- 跟住几十位挑过的作者，把他们的文章读好；
- 找到值得关注的新作者和新网站；
- 研究设计网站里能借鉴的东西，再交给 coding agent。

## 能做什么

- **首页**：一个往下滚的总览，不是列表：画廊里今天的设计例子，铺满；聚合站排得最高的几篇；每位关注作者的最新一篇；几位没关注的目录作者，每天抽一次，一人一句话路过，带订阅按钮。更早的文章都在各作者页。从探索来的文章在和探索同一个预览阅读器里打开，返回首页。启动时重新读一遍订阅。没有订阅的资料库打开在探索页。
- **订阅**：每位作者一个文章列表。没有已读、未读：不计数、不筛选、不标记已读；只记阅读进度，读到一半的文章可以接着读。
- **探索**：手挑的作者和设计网站目录（约 57 个：中文独立博客、英文设计工程师、设计写作和通讯、灵感画廊、设计展示站），加上上游推荐的作者（Hacker News 摘要、UX Collective、Latent Space、Lobsters）。每个都带最新文章和图标，订阅前就能在应用里读。分两个并排的空间：看的设计网站，读的作者。设计网站的首屏由应用在后台截取，保留 30 天。
- **阅读器**：结构化的正文；设计画廊的条目按作品页读（录屏、截图、信息）。
- **收藏**：只按作者收，一下就收，不用归类。先看收过的作者，每人站在自己的网站上；点进去再看从他那里收了什么。取消一篇或一位作者的全部收藏当场生效，可以从提示里撤销。搜索按标题或作者找。
- **摘录**：带出处。
- **交给 agent**：摘录卡把段落、出处、链接和想法复制成 Markdown，贴给 Claude Code、Codex 或笔记。
- **计划中，刻意做小**：翻译和 AI 精读。

每页具体长什么样见 [PAGES.md](PAGES.md)。

## 约束

- 联网只走应用的抓取层，只访问公网地址；网页、图片和录屏都取回存在本机，界面只显示本机的副本。
- 界面语言是中文；内容有中文和英文。
- 平台：macOS 桌面，原生界面。深色优先。
- 天体主题是气质，不是词汇：深、静、精确，落在细节和精致上。界面、文案和命名里不新增天体符号或术语；月相只表示阅读进度，轨道只表示收藏。
- 视觉规则在 [DESIGN.md](DESIGN.md)，各页规格在 [PAGES.md](PAGES.md)；改任何界面前先读。
- 阅读质量是核心，不能为任何别的功能退步。
