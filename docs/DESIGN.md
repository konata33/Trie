# Design System: Trie

本文件写全应用通用的设计规则：颜色、字、布局、层次、形状、动效、图标、场景小图形和组件。开头 YAML 里的令牌是规范的数值，正文写用法。各页自己的版面和交互在 [PAGES.md](PAGES.md)，产品定位在 [PRODUCT.md](PRODUCT.md)。

## Overview 概述

**Creative North Star: "深夜里一台做工精密的仪器"**

Trie 是用来读别人写的文章、看别人做的设计的工具。界面像深夜里一台做工精密的仪器：暗、静，每一处都精确。真正发光的只有内容：文章的文字、作品的画面、作者的头像。应用自己退到后面，不抢戏。

这份气质取自天体观测：深、静、精确。天体只是气质的来源，不是词汇表；落到界面就是细节和精致：像素级的对齐、全应用一致的细线与圆角、只在需要时出现的克制光影、沉稳收住的动效、每个状态都做完整。界面、文案和代码命名里都不新增天体符号或术语。

密度中等偏松。阅读器给正文最好的条件，资料库和侧栏像一件趁手的工具，探索页和作品页让作品本身占满画面。全产品只在一处用力：摘录。

**Key Characteristics:**
- 中性深灰，不带色偏；唯一的强调色是琥珀。
- 内容提供主要颜色和图片；应用自有的场景小图形用统一的中性灰墨线与琥珀细节，见 Illustration。
- 层次靠底色明度和 1px 细线，阴影只给真正浮起的层。
- 字号、圆角、间距各有一套固定的取值。
- 界面交互动效短、缓出；按下、选中态滑动、出现和补位带一次回弹，见 Motion 的「弹一下」。摘录生成与场景小图形的持续抖动见各自的规则。

**The Only Light Rule.** 主要颜色和图片来自文章、作品截图、作者头像、作者网站。应用自有的场景小图形是例外：只用 Illustration 规定的中性灰与少量琥珀，保持同一套手绘墨线风格。界面不提供额外的装饰色、渐变、颗粒或表情符号。

## Colors 颜色

中性深灰配一个琥珀色：灰阶完全不带色偏，以免用户误判别人设计里的配色。

### Primary 主色
- **琥珀（Amber）**（accent）：焦点环、选中、主按钮、摘录高亮、收藏后的轨道。摘录高亮底色用 accent-soft，下方加 1.5px 琥珀下划线。琥珀实底上的文字用 on-accent，对比度约 9.3:1。

### Neutral 中性色
- **窗口底色**（window）：主内容区的底。
- **侧栏底色**（sidebar）：比窗口略暗，让内容区显得更亮。
- **区块**（surface）：卡片、瓦片、截图占位。
- **浮层**（elevated）：弹出面板、对话框、作者面板。
- **输入框**（field）：输入框和可编辑区域的底。
- **细线**（line / line-soft）：分隔线和描边。line 用于需要看清的边，line-soft 用于卡片和图片的内描边。
- **悬停 / 选中**（hover / selected）：鼠标悬停用很淡的 hover；当前项和键盘选中用 selected。
- **文字四档**：text 正文与主要文字，text-2 次要文字，muted 元信息，faint 只用于非文字元素（见 The Contrast Floor Rule）。
- **危险**（danger）：只用于错误信息和删除、取消订阅这类危险操作，不用于装饰。
- **遮罩**（shade）：对话框和作者面板背后的遮罩。
- **压暗**（scrim / scrim-light）：文字压在别人的图片上时，图片边缘的渐暗，只为让文字读得清（见 The Words Over Pictures Rule）。

### Status 状态色
- **阅读进度**（moon / moon-ring）：月相符号的填充和外圈，从满到空表示读了多少。
- **名字亮度**（mag1–mag4）：侧栏作者名按最近一次更新分四档亮度，越近越亮。

### Named Rules 规则

**The One Accent Rule.** 琥珀用于焦点、选中、主按钮、摘录高亮和收藏；场景小图形只在关键细节上用少量琥珀，见 Illustration。它稀少，所以有分量。

**The Neutral Grey Rule.** 所有灰都是纯中性灰，不带蓝也不带暖；不用纯黑 #000 和纯白 #FFF。

**The Contrast Floor Rule.** 文字与底色对比度不低于 4.5:1，大字不低于 3:1。faint 在窗口底色上只有约 3.7:1，所以只给图标、禁用态和分隔记号用，不给任何文字用。

### Reading Content 正文里的颜色
这些颜色只出现在文章正文里，标的是内容的类别，不是界面装饰：
- **代码高亮：** 字符串 #D9B98C，数字 #A9BCD0，关键字 #B9B9B9，函数 #ECECEC，键名 #E6E6E6，类型 #C8C8C8，标点 #7A7A7A，注释 #8A8A8A（斜体）；代码块底 #171717。
- **提示块标签：** 说明 #8DB4F5，提示 #9CC69B，重要 #B7A3EA，注意 #D7B46A，警告用 danger。
- **作品页色名：** 画廊给作品标的颜色词（紫 #8E4EC6、粉 #E93D82、橙 #F76B15 等）用对应的色块显示；它们来自内容，不是界面色。

## Typography 字体

- **标题字体：** 系统字体（PingFang SC / SF Pro）。
- **正文字体：** 同上；阅读设置里可切换思源宋体 Noto Serif SC（SIL OFL，随应用打包）。
- **代码字体：** SF Mono。

系统字体最安静、最清楚，让内容自己说话；宋体只作为读者自选的阅读选项。正文不用 macOS 自带的宋体（Songti SC），它在屏幕上渲染偏旧。

### Reading 正文
- **字号与栏宽：** 17px，行高 1.85。每行约 32–38 个汉字，栏宽 620–680px，阅读器为 640px；段距约 0.9–1em。
- **标点与间距：** 每行行首的开引号、开括号挤成半宽，相邻标点之间多余的空白挤掉；汉字与西文字母、数字之间自动留出一点间隙；断行时避免末行只剩一两个字；标点不悬挂到栏外。
- **正文里的标题和代码：** 正文为 17px 时，一级标题 24px，二级标题 20px，三到六级标题 17px（加粗）；行内代码和表格 15px，代码块和图注 13px，代码块标题 12px。

### Named Rules 规则

**The Ladder Rule.** 字号只取 12 / 13 / 15 / 17 / 20 / 24 / 32 / 40px，不用 12.5、13.5 这类半号；要更强的层级，就跳一级。

**The Tabular Numbers Rule.** 所有数字都用等宽数字，计数和日期上下对齐。

## Layout 布局

窗口分两栏：左侧 232px 的侧栏（顶部留 46px 给窗口按钮），右侧是内容区。窗口顶部 38px 是拖动窗口的条带。阅读专注模式下侧栏隐藏，正文居中。

- **间距：** 16 以内每 2px 一档：2 / 4 / 6 / 8 / 10 / 12 / 14 / 16；16 以上取 20 / 24 / 32 / 40 / 48 / 64。按用处分三档：
  - 小（2–10）：部件内部，比如图标和文字之间、侧栏行和输入框的内边距、徽标和图标按钮的内边距。
  - 中（12–24）：条目和相关元素之间，比如列表行的上下内边距、头像和文字之间、按钮和卡片的内边距。
  - 大（32–64）：页面版块之间、页边距、阅读栏的上下留白。
- **对齐：** 图标对齐它所在那一行文字的中线，不按整行盒子居中；一排圆形图标的直径一致。
- **页面框架：** 每个顶层页都以同一条 52px 的顶带开头：左边是返回或状态，右边是搜索；顶带压在窗口拖动条之上。读文章的页和阅读器用同一栏；卡片网格最宽 1200px，左右各留 32px。搜索一律收起成一个图标，放在顶带右端。

各页的版面（首页、探索、收藏、摘录、阅读器）见 [PAGES.md](PAGES.md)。

**The Spacing Scale Rule.** 任何间距、内边距和偏移都从上面的档位里取，不另起数值。

## Elevation & Depth 层次

这套系统基本是平的，层次靠底色明度和细线表达，从暗到亮依次是：侧栏、窗口、区块、浮层。阴影只出现在真正浮起来的层上，以及别人网页的截图上，让深色网页的边缘不融进界面。

### Shadow Vocabulary 阴影

| 阴影 | 用在 | 数值 |
| --- | --- | --- |
| 浮层 | 弹出面板、菜单、摘录工具条 | 0 0 0 1px rgba(0,0,0,0.2)，0 12px 32px rgba(0,0,0,0.5) |
| 对话框 | 图片对话框、作者面板这类占据视线中心的层；背后压一层 shade 遮罩（rgba(6,6,6,0.74)） | 0 24px 64px rgba(0,0,0,0.6) |
| 截图 | 展台和面板里别人网页的截图 | 0 0 0 1px line-soft，0 16px 32px -16px rgba(0,0,0,0.8) |

### Named Rules 规则

**The Flat Until Floating Rule.** 静止的卡片、瓦片和首屏没有投影，边缘只用一圈 line-soft 内描边。

**The Blur Is a Mask Rule.** 模糊只用来遮住暂时不该读到的内容（例如探索页边缘透出的另一个空间、对话框背后的页面），或在转场里表示失焦（见 Motion 的移焦，最多 3px，转场结束就清楚）；不用来营造材质；模糊之上不叠颗粒、渐变或光泽。

**The Words Over Pictures Rule.** 字压在别人的图片上时，落在图片底部的一条压暗带上：从第一行字往下是 scrim（0.9），往上缓缓淡到透明；这条带里的图片同时模糊，图上原有的字既透不出来，也不会和我们的字混在一起。字一律用浅色，不按封面亮暗换成深色：0.9 是让 muted 文字在纯白网页上仍有 4.5:1 的最低值。scrim-light 只用在顶边的控件上（轮播进度条）。作者网站当文字卡片的底时，同样模糊，字下面同样压到 0.9，用卡片自己的颜色。

## Shapes 形状

圆角只有三档，外加胶囊：控件 6px，卡片和瓦片 10px，浮层 12px，胶囊按钮全圆。图片取其容器的圆角。描边一律 1px。

- **人和机构：** 个人作者用圆形头像；出版物、杂志等机构用 6px 圆角的方形标识。
- **站点图标：** 不垫浅色圆底。按图标自己的像素分四种处理：透明底上的深色单色图形（如 Innei、Anthony Fu）画成插画墨线灰；自带白方块的扁平标志（如 NN/g、Fonts In Use）以 0.9 的强度反相、再把色相转回，变成深底浅字，白落在 #1A1A1A、黑落在 #E6E6E6，仍在调色板里；透明底的彩色图形，以及自带深底或照片的图标，按原样显示。透明底的图形四周留 12%，免得被圆形裁掉。侧栏、作者页头、首页、收藏、摘录、通知里的站点图标都按这套处理。
- **状态符号：** 阅读进度用月相，只挂在读到一半的文章上，亮的部分是还没读的；收藏用轨道，未收藏是中心点加一段没合拢的弧，收藏后弧线合拢、变成琥珀色。这两个符号各只有这一种意思。

**The Three Corners Rule.** 圆角只能是 6、10、12px 或全圆。

## Motion 动效

### Principles 基调

**移焦。** 换页像镜头换焦点，从不剪切：离开的轻轻失焦、退后，到来的对上焦。被点的那个东西始终清楚，走到它在下一屏的位置。变的是焦点，不是内容。换页用移焦；弹窗从按钮里长出来，关掉缩回去；打开文章用「底色先动」（见 Continuity）。

四条规矩：
1. **按下就有反应：** 被点的东西在按下那一刻先变（控件被压扁，卡片和截图微微缩小，或变亮），转场在同一帧开始，中间不留空白。
2. **同时交接：** 不先关再开。走的和来的一起动，走的更快，约为来的 0.6。
3. **从哪来，回哪去：** 菜单、弹出面板、对话框、看大图、通知从打开它的那个东西里出来，关掉时回到那里。
4. **同一个东西不消失：** 两边都有的东西（文章标题、作者头像和名字、截图、页签）从头到尾是同一个，走过去，不是这边消失、那边再出现。文字按两边字号的比例缩放着走过去。

### Easing 缓动
- **标准曲线：** cubic-bezier(0.2, 0, 0, 1)，即 Material 3 的标准曲线，所有界面过渡默认用它。走到四分之一的时间时约走完 61%，减速均匀。
- **走远路的弹簧：** 标题、头像、名字、打开文章的那页纸这类走远路的东西，用不弹跳的弹簧（临界阻尼），手感接近 SwiftUI 默认弹簧（duration 0.5 秒，bounce 0）。
- **跟手的弹簧：** 会被打断、要跟手的移动（拖动、布局变化）用弹簧，duration 0.3 秒，bounce 0。
- **弹一下的弹簧：** 按下、松开和选中态滑动用带回弹的弹簧，数值见「弹一下」。
- **特殊曲线：** flight 用于长距离飞行，如头像飞进侧栏；swing 用于带阻尼的摆回，如指南针；brake 用于转动的图标匀减速停下。
- 曲线和时长只从本节取；要新曲线，先给它起名、写明用途，加进这一套，不在页面里随手写。

### Duration 时长

按距离和面积分档，退场约为进场的 0.6。越大的东西动得越慢，走得越远的动得越久。

| 档 | 动作 | 进场 / 退场 |
| --- | --- | --- |
| 小 | 悬停 | 150ms |
| 小 | 卡片、截图按下 | 120ms |
| 小 | 提示 | 200ms / 120ms |
| 中 | 菜单（一天开几十次，比其他弹层快一档） | 150ms / 100ms |
| 中 | 改字号、栏宽时正文原处淡化 | 180ms / 100ms |
| 中 | 原处换内容（看大图翻到上一张、下一张，摘录卡翻到上一段、下一段） | 250ms / 150ms |
| 中 | 弹出面板 | 250ms / 150ms |
| 中 | 控件状态 | 250ms |
| 中 | 通知 | 弹簧约 500ms / 180ms |
| 中 | 侧栏切页 | 320ms / 180ms |
| 大 | 对话框 | 400ms / 240ms |
| 大 | 看大图 | 450ms / 280ms |
| 大 | 专注模式 | 400ms |
| 页面级 | 打开文章、进作者页 | 约 600ms |
| 页面级 | 返回 | 约 460ms |
| 页面级 | 返回时列表里的月相变到读到的位置 | 420ms |

### Focus Shift 移焦的分寸
失焦最多 3px，缩放不超过 1.5%，只出现在转场里，转场结束就清楚。往里走（打开文章、进作者页）时旧的后退、新的从稍近处落定；往回走反过来。对话框打开期间，背后的页面轻轻失焦（2px），那是遮罩。

### Continuity 连续，不跳变
顺滑来自东西有来处和去处，不来自材质。
- 选中态在项目之间滑过去，而不是这一项熄灭、那一项亮起。
- 列表里有一项离开，它先收起，下面的再补上来。
- 数字变化时逐位滚动（300ms），不跳；到位前多滚一点再回来，见「弹一下」。
- 展开和收起的面板过渡高度，不瞬间撑开。
- 侧栏切页时只有内容区移焦，侧栏原地变化。
- **打开文章：底色先动。** 被点的那一行先亮起一块 selected 底，这块底展开成一页纸（正文栏左右各宽 24px，从工具条下面铺到窗口底），标题坐在纸上走到大标题的位置，正文在纸上对焦出现；纸铺满后化进窗口（约 0.2 秒）。返回时纸先浮起，正文退去，纸缩回那一行再熄掉。

### Elasticity 弹一下
压一下，弹一次，停住：顺着动作的方向变形，回正时往反方向冲过头一次再停住，第二下小到看不见。变形时面积大致不变，变宽多少就变矮多少。
- **按下：** 按钮、图标按钮、侧栏页签按下时以底边中点为原点被压扁：按钮宽 ×1.05、高 ×0.88；页签宽 ×1.04、高 ×0.88；收藏按钮、图上的「···」、看大图的圆按钮这类小按钮宽 ×1.07、高 ×0.85；看大图的圆按钮按下时还从圆形变成 10px 圆角的方，松开弹回圆形。压下用 duration 0.22 秒、bounce 0.4 的弹簧，约 200ms 到位；松开用 duration 0.35 秒、bounce 0.65 的弹簧，约 185ms 时反方向冲过头约变形量的 30%，约 400ms 停住。卡片、摘录段落、作品截图这类大面积的东西不压扁，按下时缩到 0.97–0.99。
- **选中态滑动：** 侧栏页签、作者列表、分段控件的选中底色是同一块，在项目之间滑过去。底色的两头各走一根弹簧：前头 duration 0.3 秒、bounce 0.15，后头 duration 0.45 秒、bounce 0.25。滑动途中底色被拉长，走得越远拉得越长：34px 高的底色在相邻两项之间约长出 8px，走 240px 时约长出 50px，约 100ms 时最长；落地时后头冲过头约路程的 3% 再回来，约 550ms 停稳。开关的滑块、作品页截图条下的琥珀细线也是两头两根弹簧；开关滑块拉长时同时变矮，矮下去的量是拉长量的一半。
- **数字滚动：** 每一位按标准曲线滚到新值（300ms），途中往前多滚 0.18 行，再用 160ms 回到位。
- **出现和补位：** 通知从下方 12px、放回原处的摘录段落从下方 10px 升起，用 duration 0.4 秒、bounce 0.5 的弹簧，约 230ms 时冲过头约路程的六分之一，约 500ms 停住；退场照旧。列表里有东西离开后，其余的用 duration 0.45 秒、bounce 0.3 的弹簧合拢，冲过头约路程的 5%，约 400ms 停住：收藏页的卡片和作者，摘录页的段落和人。
- **收藏轨道：** 弧线合拢时线条先变粗到约 1.5 倍再回正；卫星比弧线的头晚 60ms 出发，用 duration 0.5 秒、bounce 0.42 的弹簧转到顶上，冲过头约九分之一再摆回，约 600ms 停住。
- **菜单开着的「···」：** 菜单按下就打开，所以「···」不压扁，菜单开着时从圆形弹成 10px 圆角的方（duration 0.4 秒、bounce 0.5），关掉弹回圆形。
- **图标里的那一处填色：** 按下时墨线不动，填色那一块顺着图标的意思动一下，松开后比按钮晚 40ms 弹回。按住时用 duration 0.26 秒、bounce 0.4 的弹簧；松开用 duration 0.42 秒、bounce 0.7 的弹簧，冲过头约三分之一，约 700ms 停住。各图标的动作，按图标大小的比例计：在浏览器打开和外链箭头往右上各移 1/8；删除的提手往上 1/8；复制后面那张纸往左上各 1/8；播放的三角往右 1/8；刷新的箭头顺时针转 30°；搜索镜片上的反光绕镜片中心顺时针转 40°；首页的门以底边为准矮下去 30%；收藏和「···」中间的点放大到 1.4 倍；摘录的两个引号点往下 8%，右边那个晚 40ms。菜单按钮按下就开菜单，「···」的点在菜单开着时放大。探索、字号、时间和只有墨线的图标不动。
- 键盘触发时直接到位，不变形。减弱动态效果时不播放回弹和拉长：按下直接显示压扁后的形状，松开直接复原，底色直接到位。

### Popups 弹层
- **菜单和提示：** 从按钮长出，0.96→1，不模糊；关掉只淡出。小字一模糊就显得脏。
- **弹出面板和快捷键面板：** 用同一套弹出面板的动效。
- **对话框：** 对话框和背后的遮罩同进同出。
- 从按钮打开的弹层从按钮长出来，关掉时回到按钮；键盘打开时直接到位。

### Frequency 频率与键盘
- 一天用上百次的动作（键盘移动、搜索输入时的列表过滤）不加动画；几十次的（切页、选中）用中档。
- **键盘触发的动作不加动画。**

### Reduced Motion 减弱动态效果
不位移、不缩放。透明度、颜色、阴影和模糊的变化仍用各自的短时长，状态变化照样看得见；位置、尺寸和旋转直接到位。关键帧动画各自处理：无限循环的加载和占位改成 1.6 秒左右的慢呼吸或静止，进度照常显示。不把所有动效一律压成瞬间。

### Restraint 克制与例外
- **克制：** 不用着色器、光束、玻璃闪光或彩色光晕。
- **例外：** 摘录生成（见 Clip Card）；场景小图形按 Illustration 的持续抖动规则。

### Review 验收
新动效交付前在隔离副本里逐帧看一遍，再量一次掉帧；键盘操作和减弱动态效果各试一次。

## Icons 图标

- **画法：** 手绘马克笔线条，笔触有轻微的粗细起伏，像 claude.com 的 pictogram。全套共用一个缩放比例，保持原画给的相对大小。界面里的图标都出自这一套，页面里不另画。
- **制作：** 用 Codex 图像生成画出整张图标表，再用 potrace 描成矢量。
- **两层：** 墨线用当前文字色；最多一处填色，平时是 rgba(255,255,255,0.16)，在当前页签或点亮时变成琥珀，200ms 渐变。
- **尺寸：** 控件里 16 或 20px；12px 只用在 12px 文字行里；更大的只给空状态和预览。
- **动：** 工具栏、侧栏等控件里的图标不抖动（场景小图形按 Illustration 的持续抖动规则）。控件图标只在状态真的变化时平滑、带阻尼地动：切到探索时指南针摆一下再落定；刷新只在刷新中转，结束时缓停；按下时填色那一块动一下（见 Motion 的「弹一下」）。悬停只变亮，不做动作。键盘触发和减弱动态效果时不动。
- **刷新：** 刷新中图标顺时针转（一圈 900ms）、填色亮起；结束时转到正位匀减速停下，不回弹。
- **读取记号：** 按钮里、订阅胶囊里和 12px 状态行里的读取中都用它（整页读取中用场景小图形，见 Illustration）：用图标那支笔一笔转一圈的墨线弧，起笔饱满、收笔干细，像星轨长曝光拖尾的手绘版。跟随周围文字的颜色，匀速顺时针转，1.1 秒一圈，粗的一头在前，不抖。减弱动态效果时停住，慢慢呼吸。16px 单独用，12px 放进 12px 的行。
- **月相不在此列：** 阅读进度的月相是应用自己画的记号。
- **应用图标：** 深色底板上一片手绘枫叶，微微倾斜，分三层。
  - 浅灰的粗轮廓和主脉。
  - 更细、更暗的叶脉网，只在大尺寸里当底纹。
  - 右边一瓣填琥珀，格线用浅琥珀。

  16px 和 32px 由系统从大图缩小，不另画。

## Illustration 场景小图形

空状态、整页读取中、读不到和出错用的手绘小图形；新增同类图形一律用这套风格。原图、矢量稿、提示词和动态参考存放在仓库的[场景小图形资产库](../assets/pictograms/README.md)，以那里为基准。

- **画法：** 手绘墨线 pictogram。轮廓圆润，笔触有轻微粗细变化，保留有控制的手绘不规则；构图简洁，留白充足。参考 Claude 动态小图形的笔触与换帧感，绘制原创题材。线条粗细、圆角手感与细节密度以资产库里的两张基准图为准。
- **配色：** 透明底，浅灰墨线 #BDBDBD，关键细节用琥珀 #E3B061。墨线与琥珀分为两层；琥珀集中在一个有含义的部件或一组相关部件上，例如书签或成对的引号。主体内部保持留空。
- **题材：** 用与状态含义相关的少量物件表达一个概念。一套图靠同一支笔保持一致，不靠同一个题材；同一个比喻不反复用。
  - 空状态每页一张：收藏是书册与书签，摘录是书页与引号，作者页没有文章是信箱（琥珀小旗放下）。
  - 读取中（loading）：一架还在飞的纸飞机，四帧手绘飞行（机头微微上下、身后风线往后移），跟抖动同样 12fps，一秒一轮；减弱动态效果时停在第一帧。
  - 读不到（unreachable；网络或来源没有响应，重试可能好）：同一架纸飞机落了地，只有一小块折面是琥珀。探索推荐和阅读器正文共用。
  - 出错（broken；界面或正文显示失败，本地数据还在）：书里滑出几页纸，其中一页琥珀。
  - 正文里的图片没能载入（picture）：一幅只画了一半的画，画框和山的线在右下角停住，太阳是琥珀。占住原图的位置，知道原图比例时按原图比例，正文不会因为图后来到了而跳动。居中摆放：上面是这张图，下面一个「重试」按钮，不加文字。和其他场景小图形一样 168px、持续抖动。
- **尺寸与构图：** 在实际界面大小下校对，基准宽 168px。与说明文字组合时，插画、标题和说明保持独立层次，文字与布局稳定。工具栏、侧栏中的小尺寸操作图标按 Icons 的规则。
- **持续抖动：** 场景小图形可见时，以每秒 12 帧的离散轮廓变化持续轻轻抖动：三种轮廓循环，每轮 250ms，整体位置保持稳定。168px 宽时单轴位移约在 1.18px 以内；最终观感以动态参考为准。一直抖，不做成播放一次后静止。
- **状态与无障碍：** 视口外或窗口隐藏时暂停；减弱动态效果时用最终静态图。键盘切页不额外触发进场动作。图形作为装饰从读屏中隐藏，状态由旁边的文字说明；出错时整块作为提醒，读屏立刻读出。
- **整页读取中：** 只放 loading 这张图，不加字（「正在读取…」只给读屏），放在空状态和出错的同一位置。题材是还在路上的纸飞机：读不到时是同一架飞机落了地，两个状态接得上。不画书。控件和行内的小读取用 Icons 的读取记号。读取不到 400ms 就不出现，出现后至少停 600ms。
- **整页的空状态和出错：** 上面是图，下面一行短标题、一句话说明，出错和读不到再给能走的路：
  - 阅读器读不到正文：按钮「重试」加幽灵按钮「在浏览器打开」。
  - 阅读器正文显示失败：按钮「重试显示」加幽灵按钮「阅读原文」。
  - 探索读不到：只有一个加重的文字链接「重试」。
  - 整个界面出错：不给按钮，说明里请人关掉窗口重开。
  - 空状态：不给按钮。
  - 正文里的图片没能载入是例外：只有图和「重试」（见上方题材）。
- **用在哪里：** 收藏、摘录、作者页的空状态；收藏、探索、作者页、阅读器的整页读取中；探索和阅读器的读不到；阅读器正文和整个界面的出错；正文里的图片没能载入。搜索没有结果、按钮里和行内的小提示不用场景小图形。
- **新增图形：** 先查看基准图；生成时把它作为风格参考；在相同深色底、实际尺寸和同一换帧节奏下并排核对。题材可以变，笔触、配色、留白和动效性格保持一致。原图和分层矢量稿存进资产库。额外的小剧情动效只作试验，不替代持续抖动。

## Components 组件

### Buttons 按钮
- **画法：一笔圈出。** 按钮没有底色方块，平时只有字。指针移上去，场景小图形那支笔从左上角起笔，绕着字圈一圈（约 0.5 秒，标准曲线），移开时较快地收回。圈有短、中、长三种手绘稿，按当前显示的字数挑最合适的一个（等着换上的字不算），跟着按钮伸缩；圈比按钮略大一圈，像随手圈字。
- **Primary：** 圈一直画着，琥珀色，字加粗。每个画面最多一个。
- **Danger：** 圈一直画着，danger 色，字加粗。只用来确认删除、取消订阅这类一步。
- **Secondary：** text 字，悬停时圈出灰色的圈。
- **Ghost：** text-2 字，悬停时字变亮、圈出灰色的圈。
- **键盘焦点：** 圈立刻画好，换成琥珀色（焦点色），不另加描边框；键盘触发不播放画圈的动作。
- **按下和读取中：** 按下时被压扁，松开弹一下（见 Motion 的「弹一下」）。读取中时，圈往中间收拢、淡掉，墨线弧读取记号接着转，按钮宽度不变。
- **禁用：** 整体 0.4 透明度，悬停不画圈。
- **尺寸：** 高 32px；小号高 24px、12px 字，圈也收小。在面板或对话框里，圈收在按钮边界以内，免得被面板边缘裁掉。
- **减弱动态效果：** 圈直接出现，不画。
- **只有图标的按钮：** 必须有读屏能读出的名称；图标见 Icons。

### Navigation 导航
- **侧栏页签：** 32px 高，6px 圆角；当前页用 selected 底和 text 文字，图标的填色亮成琥珀；悬停用 hover 底。当前页签展开文字，其余只显示图标。页签不显示任何数量。
- **作者列表：** 头像和名字；名字亮度按最近更新分四档。不显示计数；不加组名，侧栏只有这一组，头像已经说明这是人。悬停只变亮：不展开最新一篇，不跑马灯，不把下面的行推开。作者多时只有列表自己滚动，页签和底部一排不动。名字默认用探索目录里的名字，不用订阅源自带的长标题。
- **刷新失败的作者：** 那一行变暗，右侧一个刷新图标，不写「重试」两个字；悬停提示「刷新失败，点击重试」；悬停时「···」照常出现在它右边。
- **侧栏底部：** 一排工具：左边「快捷键 ?」，右边「添加订阅」和「刷新」两个图标按钮。上面只放去哪儿和人。
- **作者菜单：** 「···」和右键作者行打开同一份菜单，只有三项、不带图标：重命名 / 在浏览器打开（末尾挂阅读器同款小箭头，表示会离开应用）/ 取消订阅。菜单里没有单独刷新一位作者：顶上的刷新几秒刷完全部，出错的行自带重试。
- **重命名：** 在那一行原地改，回车或点别处保存，Esc 放弃；不弹对话框、不提示「已更新」。
- **取消订阅：** 不弹确认，直接生效，那一行在 150ms 里收起，底部提示「已取消订阅 某某」，带撤销。

### Cards / Containers 卡片与容器
- **圆角：** 10px。
- **底色：** surface，带一圈 line-soft 内描边。
- **阴影：** 无（见 The Flat Until Floating Rule）。
- **内边距：** 大卡片 24px，小卡片 16px；以图片为主的瓦片不留内边距，图片铺到边缘。
- **作者的底：** 以文字为主的卡片可以垫上作者自己网站的截图，压暗后放在文字读完的下半部分，保证文字始终落在接近黑的底上；没有截图的作者用其头像的两种主色做柔和的晕染，不加颗粒、不做漂移动画。

### Overlays 浮层
- **弹出面板：** elevated 底、line 描边、12px 圆角、浮层阴影。
- **对话框与作者面板：** elevated 底、12px 圆角、对话框阴影，背后加遮罩；Esc 和点击遮罩都能关闭，关闭后焦点回到打开它的元素。

### Inputs / Fields 输入框
- **样式：** field 底、6px 圆角、高 32px。
- **焦点：** 2px 琥珀描边。
- **出错：** danger 色的一句话说明，写清原因和下一步。

### Scrollbar 滚动条
全应用不显示系统滚动条，用自己的：首页、收藏、作者页、摘录、阅读页共用内容区的一把；探索页用自己的一把，打开来源详情时藏起来。它读起来像一件量具。
- **平时：** 看不见。一滚动，窗口右边缘浮出一把刻度尺，从离顶 48px 起，到离底 10px 止，整把尺代表整页内容。顶部 38px 是拖动窗口的条带，按在那里拖动的是窗口而不是指针；48px 也正是各页内容的起点。
- **刻度：** 按尺子的习惯二分：两端和中点的刻度最长（11px），四分点 8px，八分点 6px，其余 4px。
- **指针和灯：** 一根指针横过尺子，停在当前位置，一眼能读出「在上半部、过了中间一点、快到底」。指针上挂着一盏灯，靠近的刻度变亮、远了暗回去（余弦衰减，52px 内）；灯照到的地方多出四分之一格的细分刻度，别处没有，像放大镜。
- **线：** 除指针外所有线都是一个物理像素粗；指针粗一点、亮一点，左端渐隐。
- **出现和消失：** 出现时光从指针往两端铺开（最远的晚 140ms），消失时两端先暗、光收回指针里。出现用 150ms；停下 900ms 后在 400ms 里淡出。
- **靠近和拖动：** 鼠标移到右边缘 24px 内：刻度亮一档，灯照得更远，指针变长，可以拖；鼠标所在处出现一根很淡的虚影指针，表示按下去指针会落到这里，按下后页面平滑滑过去。拖住时指针全白、灯最远；鼠标甩出尺子也不断。
- **内容变长：** 内容接上新的一批时，指针和灯一起在 250ms 里滑到新位置。
- 不画「当前看到的那一段」。

### Status 状态
- **没有已读、未读：** 不计数、不筛选、不手动标记，也不自动标记。只记阅读进度：读到一半的文章挂月相，没开始的和读到结尾的都不挂。收藏用轨道（见 Shapes）。
- 「有更新」「仅摘要」用文字标签，不冒充全文。
- 状态符号永远比标题安静，不能成为画面里最抢眼的元素。

### Clip Card 摘录卡
全产品唯一用力的地方。在文章中划下一段，或在设计截图里框住一块，它变成一张带出处的卡片：内容本身、作者或站点、原文链接、摘录日期；设计摘录另含配色和字体。这里允许比其他地方更讲究的动效与质感。
- **引文：** 卡片顶上是说这话的人：头像、名字，名字后面是文章的发表日期（12px muted，今年的不写年份，和首页、探索页「名字 · 时间」同一个写法），另一头是翻页和关闭。摘下的段落用阅读正文的字号和行距（17px / 1.85；100 字以内 20px，40 字以内 24px），手绘引号挂在段首左侧。下面一行只有出处《文章标题》，标题就是回原文的路：带下划线，点它（或 Tab 到它按回车）在阅读器里打开这篇、落到这一段，悬停提示「在原文中看这一段」。没有单独的「打开原文」按钮。
- **跟着人走：** 卡片顶上晕开这个人头像的颜色，和摘录列表里一样；翻到另一个人时，颜色、头像和名字跟着段落一起交叠过去，同一个人之间翻页时它们不动。
- **页边的想法：** 段落右边留一栏 176px 的页边，和段落隔 48px，第一行和段落第一行对齐：琥珀短线加想法（点一下原地改，离开就存，Esc 放弃；两行时平衡断行，不留单字）。没写想法时只有一个幽灵按钮「写下为什么摘它」，不画短线。
- **卡片底边：** 左边是「摘于 几月几日」（12px muted，像书后的借阅章），和发表日期分开，两个日期都压到最小一档；右边是删除（垃圾桶图标，悬停变 danger，删了有撤销）和琥珀主按钮。
- **交给 agent：** 每张卡只有一个琥珀主按钮「复制引文」，把段落、出处、链接和想法整理成 Markdown 复制（作者和博客名不同时两个都带上），贴给 Claude Code、Codex 或笔记都行。按钮不带图标；悬停提示写清复制了什么。
- **复制成功：** 被复制的东西亮一下：正文每一行、出处那一行和页边的想法，同时从左往右刷上一层 accent-soft（阅读器摘录高亮的颜色），停一会儿，再从左往右褪掉，全程约 1.1 秒，让人看见带走的是哪几样；按钮原地换成「✓ 已复制」，对勾像笔画一样从左往右画出（250ms），2 秒后换回。列表悬停条里的复制同样让那一段的开头和想法亮一下。键盘触发时不播，减弱动态效果时只淡入淡出不横扫。
- **复制失败：** 显示「复制失败」，提示改成「没能复制，再按一次试试」。
- **打开的仪式：** 卡片从点击的那一行长出来；落定后段落、出处和想法从下方 4px 带 2px 模糊淡入（180ms），接着引号的两个圆点亮成琥珀（200ms），全程不到半秒。翻到上一段、下一段只做快速交叠。键盘打开或翻页、减弱动态效果时直接到位。
- **原文里的摘录高亮：** 原文里摘过的段落带摘录高亮（accent-soft 底加 1.5px 琥珀下划线），悬停提示「已摘录」。

## Do's and Don'ts 该做与不该做

### Do 要
- **Do** 让内容提供主要颜色和图片，界面与场景小图形用本文件规定的中性灰和琥珀。
- **Do** 字号、圆角、间距只从各自的数列里取值。
- **Do** 每个状态都做完整：悬停、焦点、按下、加载、空状态、出错。列表走到底不加「到底了」之类的标记；只有阅读器文末有结束标记，用来分清读完和来源只给了摘要。
- **Do** 像素级对齐：图标对齐文字那一行，日期并入说明行，一排图标逐个量中心点。
- **Do** 郑重对待作者：凡是出现内容的地方，作者头像、名字和日期都清楚可见。
- **Do** 快捷键说明放进按钮的悬停提示、菜单或快捷键面板。

### Don't 不要
- **Don't** 使用装饰性渐变、颗粒、噪点、光晕或表情符号。
- **Don't** 在界面、文案或代码命名里新增天体符号或术语；月相表示阅读进度、轨道表示收藏，只有这两个。
- **Don't** 统计或标记已读、未读，也不要用「N 篇未读」这类数字催人；订阅一位有一百篇旧文的作者，首页只是多出一百篇按时间排好的文章。
- **Don't** 为风格套用比喻，把画面做成报纸、书架、终端或代码编辑器（活动栏、文件树、编辑器标签页）。
- **Don't** 给静止的卡片加投影，也不用通栏灰块做选中态。
- **Don't** 用纯黑、纯白或带色偏的灰。
- **Don't** 用 faint 写任何文字。
- **Don't** 在产品界面里放教程或演示文字。
