# 0029 移除 Electron 旧版

- 状态：采用
- 日期：2026-11-12

## 背景

[0012](0012-从Electron换成MyGo原生界面.md) 决定用 MyGo 重写，[0027](0027-新版换上真实资料库.md) 让新版打开真实资料库，同时保留 Electron 旧版作为退路。新版已经日常使用，旧版不再更新。两版并存时，规范要同时照顾两套实现，规范文件放在旧版目录下，仓库里还混着旧版的依赖、构建产物和核验材料。

## 决定

维护者定：从仓库中移除 Electron 旧版（`apps/desktop`）。

- 全应用的规范（PRODUCT、DESIGN、PAGES、READER_ENGINE）移到 `docs/`。
- 只描述旧版代码写法的规范（StyleX、Base UI 的用法和文件边界）随旧版删除。
- 仓库只保留一个应用：`apps/mygo`。

## 考虑过的其他做法

- 继续保留旧版作为退路：没选。新版已经替代旧版，维护两套实现的成本高于退路的价值；需要时可以从版本历史取回。

## 影响

- 0027 中「旧版保持可用」和新旧两版的互锁不再成立。新版去掉了对旧版的检测，只保留自己的资料库锁：同一个资料库一次只能被一个 Trie 窗口打开。
- 新版代码注释里指向旧版文件的移植来源说明一并删除；迁移期间用来对照新旧两版的演示程序（`cmd/motion-spike`、`cmd/reader-spike`）也删除。
- 真实资料库目录里旧版留下的浏览器缓存清掉，清理前完整备份。
- 场景小图形从原图到应用内 SVG 的转换原来经由旧版的组件文件，现在直接把描线结果写成 `apps/mygo/internal/app/art/` 下的 SVG（见 [assets/pictograms/README.md](../../assets/pictograms/README.md)）。
