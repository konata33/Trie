# 0017 阅读器工具条往下读让开

- 状态：采用
- 日期：2026-11-10

## 背景

规范原来写阅读器「工具条贴在顶部，滚动时停住」，和旧版的实际做法不符：实际是往下读时让开，往上滚时回来，标题滚过以后栏上显示标题。MyGo 新版照规范的写法做，漏了这些；维护者指出是规范写错了，随后改正。

## 决定

以旧版的实际做法为准：往下读让开，往上滚回来，标题滚过后栏上显示标题；规范改正（见 PAGES.md 阅读器）。

## 考虑过的其他做法

- 工具条贴在顶部、滚动时停住：没选，这是规范写错的，旧版从来不是这样。

## 影响

- 当时定下：搬旧版界面以旧版实际的样子和代码为准，发现规范和旧版不一致就告知维护者。
