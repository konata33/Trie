# 0010 滚动条做成刻度尺

- 状态：采用
- 日期：2026-11-08

## 背景

系统滚动条在 Chromium 里没法只换样子：用 CSS 改，会变成一直显示、还占宽度的老式滚动条。

## 决定

全应用藏掉系统滚动条，自己画一把刻度尺：平时看不见，滚动时浮出，指针停在当前位置，读起来像一件量具（见 DESIGN.md Components / Scrollbar）。

## 考虑过的其他做法

- 用 CSS 给系统滚动条换样子：没选，见背景。
- 把「当前看到的那一段」画成亮段：没选，页面短的话它会占满整把尺，白一大片还读不出位置。
- 用发丝线括号加钳口标出看到的那一段：评审后未采用。

## 影响

- 能滚动的页面都要接上这把尺；它只标位置，不标看到的范围。
