# 0027 新版换上真实资料库

- 状态：采用
- 日期：2026-11-12

## 背景

新版各页已经搬完，并对照旧版验收过。原计划先用资料库副本试用一两天再切换。两版共用 `~/Library/Application Support/BlogShelf`：同时打开时，各自的改动和缓存会互相覆盖。

## 决定

维护者定：不做试用版，直接切换。

- 正式打包的 Trie.app 打开真实资料库；从源码运行时仍只能用副本，指向真实资料库会拒绝启动。
- 一个资料库同一时间只能由一个应用打开：Trie 开着时旧版不启动，旧版开着时 Trie 不启动，两边都弹提示说明原因。
- 切换前把资料库完整备份到 `~/Library/Application Support/BlogShelf Backups/`，校验过数据库完整性和各表条数。

见 AGENTS.md「资料库」。

## 考虑过的其他做法

- 先做试用版，用副本试一两天：没选，维护者决定直接切换。
- 新版用自己的资料库目录：没选。两版共用一份资料，旧版才能随时退回。
- 只靠 SQLite 自己的文件锁：没选。它只管单次写入，管不住两个应用各自改资料、各写各的缓存文件。

## 影响

- 维护者日常用 `/Applications/Trie.app`。旧版保持可用：退出 Trie 后打开旧版，用的是同一份资料。（旧版已移除，见 [0029](0029-移除Electron旧版.md)。）
- 打出新版本后要装进 `/Applications` 才生效，装之前先确认 Trie 已退出。
