# 0006 打开文章底色先动

- 状态：采用
- 日期：2026-11-08

## 背景

从列表打开文章需要一个转场。阅读页和列表是同一个底色。

## 决定

维护者定「底色先动」：被点的那一行先亮起一块底，展开成一页纸，标题坐在纸上走到大标题的位置，正文在纸上对焦出现；返回时反过来（见 DESIGN.md Motion / Continuity）。

## 考虑过的其他做法

- 阅读页从那一行展开成整页（MyGo 的做法）：试过，没选；阅读页和列表同一个底色，看起来只有字在飘。

## 影响

- 摘录卡打开原文走同一个转场，卡片的底展开成阅读器的纸（见 PAGES.md 摘录）。
