# 0022 首页、收藏、摘录规范按旧版实际做法改正

- 状态：采用
- 日期：2026-11-12

## 背景

搬首页、收藏、摘录时，对照旧版代码发现规范有几处和实际不符：首页设计例子的顶部压暗、「还没关注的博主」那一行的底色、走速和订阅按钮的样子；收藏画面在纯白网站上指上去的亮度；摘录里引文再大一级和旁批的条件。其中那一行的底色是规范改写成使用说明时写错的（原意是「和侧栏一样的深色」）。

## 决定

照旧版的实际做法改正规范，同 0017、0019 的处理方式（见 PAGES.md 首页、收藏、摘录）。

## 考虑过的其他做法

- 改程序去符合规范：没选。这几处都是规范落后于实际，维护者看到、认可的是旧版的样子。

## 影响

- 收藏的「···」按钮：规范原来写实心深色圆、指到名字旁才出现；旧版是 72% 不透明的深色圆、指到整幅画面就出现。维护者定照旧版，规范已改。
- 首页的间距：规范写只取 16/24/48/64，旧版版块内部还用 6、8、12、32。维护者要求参照现在流行的设计系统重新定间距规则，另见后续记录。
