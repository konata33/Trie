# 0002 没有已读未读

- 状态：采用
- 日期：2026-11-07

## 背景

订阅一位作者会带进他的全部旧文。常见的阅读器在这里给未读计数、已读未读筛选和标记。

## 决定

不计数、不筛选、不手动标记，也不自动标记，只记阅读进度：读到一半的文章挂月相（见 DESIGN.md Components / Status）。2026-11-08 侧栏跟着去掉了数量：页签不显示任何数量，作者列表不显示计数。

## 考虑过的其他做法

- 未读计数、已读未读筛选和标记：没选，用数字催人；订阅一位有一百篇旧文的作者，首页只是多出一百篇按时间排好的文章。

## 影响

- 按钮和提示里不出现「未读」。
- 月相只有阅读进度这一种意思（见 0003）。
