# 0021 应用名叫 Trie

- 状态：采用
- 日期：2026-11-11

## 背景

应用原来叫 BlogShelf，这个名字只说了内容是博客，再加一个书架的比喻。维护者想换一个英文名，要求两点：一是有极客气质，二是像 Folo 那样，从一个说清用途的普通词变成一个短词（Folo 由 Follow 演变而来）。

## 决定

维护者定的名字：Trie。

Trie 是前缀树，名字取自 retrieval（检索），读音同 tree。

- 它是一棵树，应用图标就是这棵树上的一片叶子（见 [0020](0020-应用图标用叶脉枫叶.md)）。
- 它为检索而生：应用做的，正是把值得借鉴的内容找出来、取出来，再交给 coding agent。

## 考虑过的其他做法

- **UXBlog**：最初的想法。只说了内容格式，范围也窄，听着像一个博客网站。
- **Samara、采风**：评审后未采用。
- **枫页、叶语、流连**：要的是英文名。
- **Boro**（由 Borrow 压缩而来）：极客气质不够。
- **Leaf、Folio、Glean、Ginkgo、Tilde、Linger、Lamplit、Amber、Magpie**：没选，各有冲突：
  - App Store 上已有同类应用同名，或者撞上有名的开发者项目。
  - Folio 和 Folo 只差一个字母。
- **Graft**：英语里还有贿赂、植皮的意思。
- **Parse**：会让人想起 Facebook 关掉的同名后端服务。

## 影响

- **改了的**：新版的应用名、菜单栏和窗口标题，规范和开发指南里的产品名。
- **新版的 Dock 图标**：用 `go run .` 或直接运行二进制时，程序没有应用包，现在启动后会自己把 Dock 图标设成应用图标。打包后的应用用包里的图标。
- **当时没改的**：代码、目录和环境变量里仍叫 BlogShelf，包括 Go 模块、数据目录的环境变量、资料库目录、发给网站的 User-Agent。旧版也没改名，因为它的资料库目录跟着应用名走。这些后来都改了，见 [0028](0028-内部名字也改叫Trie.md)。
- **读音**：有人会把 Trie 念成 try。
