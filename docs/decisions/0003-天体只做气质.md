# 0003 天体只做气质

- 状态：采用
- 日期：2026-11-08

## 背景

设计讨论里用过「深夜里一台做工精密的仪器」这个比喻，维护者确认的是天体观测的气质：深、静、精确。界面里原来有直接搬来的天体图形：侧栏的日食刷新图形、新文章的流星、读取中的星轨转圈。

## 决定

天体只作气质，落在对齐、细线、圆角、克制的光影和收住的动效这些细节上；界面、文案和代码命名里不新增天体符号或术语。应用自己的记号只留两个：月相表示阅读进度，轨道表示收藏。2026-11-08 去掉了日食刷新图形和流星，星轨转圈换成墨线弧（见 0009）。

## 考虑过的其他做法

- 把天体符号和术语搬进界面：没选，符号会抢内容的戏，界面要退到内容后面（见 DESIGN.md Overview）。

## 影响

- 新的图形和文案按 DESIGN.md Don'ts 里这一条检查。
