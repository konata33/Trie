# 0007 一条缓动曲线和分档时长

- 状态：采用
- 日期：2026-11-08

## 背景

原来的缓出曲线 cubic-bezier(0.23, 1, 0.32, 1) 在四分之一的时间里就走完了 78%，什么都像一闪而过。页面级的标题飞行：2026-11-04 维护者认可过半速的版本，2026-11-08 复看时认为动效过快。

## 决定

对照 Material 3、Carbon、Fluent 2、SwiftUI 以后：全应用只用 Material 3 的标准曲线，同一时刻约走到 61%，减速均匀；走远路的东西用不弹跳的弹簧；时长按距离和面积分档，退场约为进场的 0.6；页面级放慢到约 600 / 460ms，并换成弹簧。数值见 DESIGN.md Motion / Easing、Duration。

定档时参照的数值：Material 3 短 50–200、中 250–400、长 450–600ms；Carbon 微交互 70–110、中 150–240、大 400–700ms；Fluent 2 50–500ms；SwiftUI 默认弹簧 0.5 秒。

## 考虑过的其他做法

- 留着 cubic-bezier(0.23, 1, 0.32, 1)：没选，见背景。
- 页面级保持 11-04 的半速标题飞行：没选，动效过快。
- 减弱动态效果时把所有动效压成 0.01ms：没选，状态变化会看不见；改成只去掉位移和缩放，透明度、颜色、阴影和模糊的变化保留短时长。

## 影响

- 曲线和时长只从一处取（新版是 `internal/motion`）：别处不写曲线和时长，退场比进场短。
