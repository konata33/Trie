# 0012 从 Electron 换成 MyGo 原生界面

- 状态：采用
- 日期：2026-11-09

## 背景

维护者看到 MyGo 云音乐（下载 8MB、后台约 100MB 内存），提出能否从 Electron 换过去。当时评估过风险：界面和后台都要重写；MyGo 才发布约六周，一人维护。

## 决定

走原生界面，功能和样子原样搬。新版在 apps/mygo，旧版在新版追平前保持可用。

## 考虑过的其他做法

- 网页窗口（保留 React 界面，后台换 Go）：没选，macOS 上会换成 Safari 内核，动效要重新验一遍。
- 混合（侧栏列表原生，阅读页嵌网页）：没选，跨两边的转场最难做。

## 影响

- 正文用自己的原生渲染显示。
- AVIF 下载后用系统自带的 sips 转格式。
- MyGo 不能播放 H.264 等视频。
- 拿不到选区位置，摘录工具条靠重新排版算位置。
- Go 版正文提取用 readeck 的 go-readability，和 Mozilla 原版在 193 页真实网页上差不到千分之一的字。
