# 0008 按钮一笔圈出

- 状态：采用
- 日期：2026-11-08

## 背景

按钮原来是实底的：主按钮琥珀底配 on-accent 字，次按钮 selected 底，幽灵按钮悬停时垫 hover 底。

## 决定

维护者定「一笔圈出」：按钮没有底色方块，平时只有字；悬停时场景小图形那支笔绕着字圈一圈，主按钮和危险按钮的圈一直画着（见 DESIGN.md Components / Buttons）。

## 考虑过的其他做法

- 实底按钮：被一笔圈出取代；原文没有记下比较时的理由。

## 影响

- 琥珀实底只剩订阅胶囊这类控件，on-accent 留给它们。
- DESIGN.md 开头的按钮令牌到 2026-11-10 改写时才改成透明底。
