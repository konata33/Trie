# 0009 读取中用墨线弧和纸飞机

- 状态：采用
- 日期：2026-11-08

## 背景

控件里的读取中原来是星轨转圈；阅读器的整页读取中原来是作者头像对焦。

## 决定

维护者定：按钮、订阅胶囊和 12px 状态行里用墨线弧读取记号，是图标那支笔一笔转一圈；整页读取中只放一架还在飞的纸飞机，不加字，读不到时是同一架飞机落了地（见 DESIGN.md Icons「读取记号」、Illustration「整页读取中」）。

## 考虑过的其他做法

- 星轨转圈：换成墨线弧，和手绘图标用同一支笔。
- 书本翻页的读取记号：被否，原文没写原因。
- 整页读取中画书：没选，书已经用在收藏、摘录和出错的图里，同一个比喻不反复用（见 0004）。
- 阅读器的头像对焦：废弃。

## 影响

- 读不到的图跟着用同一架纸飞机，两个状态接得上。
