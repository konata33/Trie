# 0016 摘录卡先看人

- 状态：采用
- 日期：2026-11-09

## 背景

2026-11-08 的摘录卡有两个显眼的日期、一个单独的「打开原文」按钮，主按钮叫「复制给 Claude Code」。

## 决定

2026-11-09 摘录卡改成先看人：顶上是说这话的人，晕开他头像的颜色，翻到另一个人时颜色跟着换；出处的文章标题就是回原文的路；段落右边留一栏页边写想法；发表日期和摘录日期都压到最小一档；每张卡只有一个主按钮「复制引文」（见 DESIGN.md Components / Clip Card）。

## 考虑过的其他做法

- 单独的「打开原文」按钮：没选。评审时提出这个入口不一定要叫「打开原文」，改成标题带下划线，点它回原文。
- 两个日期用显眼的字号：没选，两个日期过于抢眼。
- 按钮叫「复制给 Claude Code」：没选，按钮只是复制，不会真的发给谁，用一个产品名既不准又把用法说窄了，字也太长；维护者同意改名。

## 影响

- 打开原文和从列表打开文章走同一个转场（见 0006）。
