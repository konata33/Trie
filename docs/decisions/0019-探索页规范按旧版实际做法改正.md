# 0019 探索页规范按旧版实际做法改正

- 状态：采用
- 日期：2026-11-11

## 背景

搬探索页时发现，规范里有几处和旧版的实际做法不符：写作封面的构成和底图、新卡片是否单独淡入、画廊卡片带进面板的是哪一件作品、关闭面板后哪些字淡回、取消订阅时那一行收起的时长，以及侧栏取消订阅的提示写成「和探索页一致」（探索页其实没有提示）。

## 决定

照旧版的实际做法改正规范，由维护者决定。改动见 PAGES.md 探索一节和 DESIGN.md Components 的取消订阅。

## 考虑过的其他做法

- 改程序去符合规范：没选。维护者日常看到、认可的是旧版的实际样子。

## 影响

- 新版的探索页照旧版代码实现，不用再改。
- 和 0017 一样：搬界面以旧版实际的样子和代码为准，规范和旧版不一致时告知维护者。
