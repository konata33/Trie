# 0004 手绘图标和场景小图形

- 状态：采用
- 日期：2026-11-08

## 背景

2026-11-07 图标定成手绘马克笔线条，参照 claude.com 的 pictogram，用 Codex 图像生成画整张图标表，再用 potrace 描成矢量。空状态、读取中、读不到和出错还没有用同一支笔画的图。

## 决定

2026-11-08 维护者确认场景小图形的风格：手绘墨线 pictogram，浅灰墨线加一处琥珀，可见时持续轻轻抖动，以仓库 assets/pictograms 里的基准图为准（见 DESIGN.md Icons、Illustration）。一套图靠同一支笔保持一致，不靠同一个题材，同一个比喻不反复用。同一天加了正文图片没能载入的那张（picture）。
