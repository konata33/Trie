# 0025 改字号保住读到的那一段

- 状态：采用
- 日期：2026-11-12

## 背景

阅读器里改字号或栏宽，正文要换成新的排版。旧版用整块淡化来过渡：过渡期间正文空白约 180ms；换完以后滚动位置的数值不变，但上面的文字变长或变短，读到的那一段被挤开，实测下移约 150px。新版搬到这里时要决定照搬还是改。

## 决定

新版的旧文字在原处淡出、新排版淡入，中间不留空白；换完以后正在读的那一段留在原来的位置。见 PAGES.md 阅读器。

## 考虑过的其他做法

- 照搬旧版的空白和跳位：没选。改字号的人正在读，读到的地方被挤走就得重新找。

## 影响

- 旧版的这个过渡不改，两版在这一处表现不同。
- 改字号或栏宽时选中的文字会被清掉，旧版会保留。
