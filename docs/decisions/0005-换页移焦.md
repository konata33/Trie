# 0005 换页移焦

- 状态：采用
- 日期：2026-11-08

## 背景

2026-11-07 先定了「连续，不跳变」：顺滑来自东西有来处和去处，不来自材质。移焦的来处是应用里已有的两个转场：阅读器打开时的「对焦」，首页最新一篇点开时标题不动。参考的是 iPhone Duo 的开合：变的是焦点，不是内容。

## 决定

维护者定：换页用移焦；弹窗从按钮里长出来，关掉缩回去；打开文章用「底色先动」（见 0006）。细则见 DESIGN.md Motion 的 Principles、Focus Shift、Popups。

## 考虑过的其他做法

- 菜单打开时也带模糊：没选，小字一模糊就显得脏，菜单打开的效果也不够精致；菜单只从按钮长出，关掉只淡出。

## 影响

- 转场里允许不超过 3px 的模糊表示失焦，所以 DESIGN.md 的 The Blur Is a Mask Rule 写了这个例外。
