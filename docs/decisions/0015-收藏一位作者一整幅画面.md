# 0015 收藏一位作者一整幅画面

- 状态：采用
- 日期：2026-11-09

## 背景

2026-11-07 的收藏用「上图下字」的作者卡片和文章卡片。

## 决定

2026-11-09 重做：一位作者一整幅画面（见 PAGES.md 收藏）。同时定下：最近收的三篇不标日期；作者那一幅不推近；「···」按钮用 32px 深色实底圆；整位作者取消收藏用 ⌘⌫，对应 Finder 的「移到废纸篓」，单按 ⌫ 不动作者；进作者时两边的画按原尺寸贴顶，由收拢的框裁掉。

## 考虑过的其他做法

- 「上图下字」的卡片：被否，太朴素，没有沉浸感，也找不到删除。
- 最近收的三篇标发表日期：没选，这里按收藏先后排，标发表日期会和顺序打架。
- 作者那一幅在指针停住时推近：没选，整页都是画面，推近会一直在动。
- 「···」按钮用模糊当材质：没选，模糊不用来营造材质（DESIGN.md The Blur Is a Mask Rule）。
- 进作者时两边的画各自缩放：没选，会出现两个头像的重影。

## 影响

- 压暗椭圆的尺寸要在容器里按宽度算：Chromium 不接受渐变尺寸里 % 和 px 混算。
