# 0014 整页状态按现有做法

- 状态：采用
- 日期：2026-11-09

## 背景

场景小图形接进空状态、读不到和出错以后，要定整页状态里放哪些字。2026-11-09 试过整页也只放图和一个按钮、不加字。

## 决定

维护者定还是按现有的做法：上面是图，下面一行短标题、一句话说明，出错和读不到再给能走的路（见 DESIGN.md Illustration「整页的空状态和出错」）。只有正文里图片没能载入那一处，只放图和「重试」。

## 考虑过的其他做法

- 整页只有图和一个按钮、不加字：试过，没选，维护者定还是按现有的做法。

## 影响

- 整页读取中仍然只放图、不加字（见 0009）。
