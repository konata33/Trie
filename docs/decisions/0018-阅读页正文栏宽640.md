# 0018 阅读页正文栏宽 640

- 状态：采用
- 日期：2026-11-11

## 背景

规范写阅读页正文栏宽 660px，旧版实际显示的是 640px：正文放在一个 720px 宽、左右各留 40px 的容器里，660 被它限成了 640。日常使用中看到的一直是 640。

## 决定

正文栏宽定为 640px，由维护者决定。规范改成 640（见 PAGES.md 阅读器、DESIGN.md Typography 的 Reading）。

## 考虑过的其他做法

- 660px：照规范原来的数字。没选，维护者习惯并认可的是实际看到的 640。

## 影响

- 新版的阅读栏宽本来就是 640，不用改；旧版的实际显示也不变。
- 栏宽 620–680px 的通用范围不变，640 在范围内。
