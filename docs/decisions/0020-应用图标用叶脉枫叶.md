# 0020 应用图标用叶脉枫叶

- 状态：采用
- 日期：2026-11-11

## 背景

新版还在用 MyGo 自带的占位图标，一个蓝紫渐变的圆圈。应用需要一个正式图标。方向朝 Linear 的图标风格走，主题是树叶的结构，不一定是枫叶。

## 决定

由维护者决定：深色底板上一片手绘枫叶，分三层（细则见 DESIGN.md Icons 的「应用图标」）。

- 粗的浅灰轮廓和主脉，撑住小尺寸。
- 细而暗的叶脉网，只在大尺寸里当底纹。
- 一瓣琥珀色，它的格线用浅琥珀。

整片叶子只有这一瓣亮着，就像读完一篇，只留下想借鉴的那一段。

## 考虑过的其他做法

- **照 Linear 做银色金属的叶子**（试过叶脉切缝、银杏扇、两面光影、刻线轮廓、一片琥珀叶）：没选。维护者选了手绘线描、一瓣琥珀的方向。
- **在手绘方向上发散的另外七版**（精修、透光的一瓣、叶和翅果、标本、一笔画套色、水墨、构造线）：没选。维护者选了其中的叶脉网，接着往下改。
- **叶脉网原版**：没选，有三个问题。缩到 64px 以下叶脉网就成了一层灰雾；线条像版画，不像应用自己的笔触；深色格线把琥珀压暗了。分成三层以后，这三个问题都解决了。
- **叶脉网加透光**（那一瓣像被身后的光照透）：没选。维护者选了不透光的版本。
- **为 16px 和 32px 单独画简化版**：没用。粗轮廓缩到 32px 还认得出叶子和那一瓣琥珀。

## 影响

- 图标的源文件是 `apps/mygo/resources/icon.png`，1024px，透明底。底板为 824px，四边各留 100px，带阴影。MyGo 打包时会从它生成各个尺寸。
- 这张图是 AI 生成后清理过的位图，没有矢量源。要改叶子的形状，只能重画。
- 直接用 `go run .` 或直接运行二进制时，程序没有应用包，启动后由程序自己把 Dock 图标设成这张图，见 [0021](0021-应用名叫Trie.md)。
- 旧版 Electron 没有换图标。
